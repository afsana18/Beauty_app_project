## 📌 Project Overview

End-to-End Quality Assurance Testing of the Beauty Mobile Application.

This project demonstrates my experience as a Junior Software Quality Assurance Engineer by performing comprehensive testing on a personal grooming and beauty service application.

The testing process included:

- Functional Testing
- API Testing
- UI Testing
- Regression Testing
- Smoke Testing
- Bug Reporting
